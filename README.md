# 🛒 Amazon Clone

A responsive e-commerce website inspired by Amazon, built using HTML, CSS, and JavaScript.

## 🚀 Features

- 🏠 Responsive homepage
- 🔍 Product search functionality
- 📦 Product listing
- 🛍️ Add to Cart functionality
- 🛒 Shopping cart
- ❤️ Product wishlist UI
- 📱 Responsive design for different screen sizes
- 🎨 Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
